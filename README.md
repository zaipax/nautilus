# Nautilus

Native Windows x64 Pearl miner for NVIDIA RTX 20 / 30 / 40 / 50 series GPUs. Use a current NVIDIA driver.

[Download v0.2.4](https://github.com/zaipax/nautilus/releases/tag/v0.2.4)

Extract the ZIP, edit your wallet and worker in START-MINING.bat, then double-click it. Press Ctrl+C to stop.

The live dashboard shows GPU and share statistics, plus 15-second, 15-minute and 1-hour average hashrates. An asterisk marks a window that is still filling.

Physical hardware testing currently covers RTX 5060 Ti. Compatibility kernels for RTX 20/30/40 passed correctness checks on that GPU; testing on those cards is pending.

The ZIP contains only nautilus.exe and START-MINING.bat. Run nautilus.exe --help for options or --licenses for embedded third-party notices. The ZIP SHA256 is on the release page.
